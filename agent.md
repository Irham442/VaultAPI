# VaultAPI - Project Instructions

## Project Overview
VaultAPI is a credential management application built with Python, FastAPI, and SQLite.

## Development Guidelines
- Follow the existing project architecture.
- Keep database operations separate from API routes.
- Keep authentication and authorization logic separate.
- Use Argon2 for password hashing.
- Use parameterized SQL queries.
- Maintain proper foreign key relationships.
- Avoid unnecessary dependencies.

## Learning Guidelines
- Explain important technical decisions.
- Prefer incremental implementations.
- Do not rewrite existing code without a good reason.
- Explain new concepts before introducing complicated implementations.
- Let me review the implementation before moving to the next feature.

## Working Rules
- Inspect existing code before making changes.
- Never assume an existing feature is incomplete without checking.
- Do not delete existing functionality unnecessarily.
- Run relevant tests after modifying code.
- Report modified files and test results.
- Ask before performing destructive database operations.
